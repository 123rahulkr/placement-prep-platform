# Placement Prep Platform

An AI-powered, all-in-one placement preparation platform for students.

## Features

- AI Resume Analyzer with ATS scoring
- AI Mock Interview with follow-up questions
- Personalized DSA Roadmap using RAG
- GitHub Project Reviewer
- Job Application Tracker

## Tech Stack

- Frontend: React, Vite, Tailwind CSS
- Backend: Node.js, Express, MongoDB, Redis
- AI: OpenAI API, LangChain, vector embeddings
- DevOps: Docker, GitHub Actions, AWS EC2, Nginx

## Getting Started

```bash
git clone https://github.com/YOUR_USERNAME/placement-prep-platform.git

# Install server dependencies
cd server && npm install

# Install client dependencies
cd ../client && npm install

# Run both (from root)
# See phase-specific README sections below
```
